# Claude 连接与用量统计

## 使用与采集范围

1. 右上角选择 **Claude**。不登录也能导入配置目录已有的 Claude Code 用量记录；今日 / 近 7 天 / 近 30 天均按记录的真实发生时间筛选。
2. 「登录 Claude Code」只在终端打开已有、未修改的官方工具 `auth login`。浏览器授权、验证码和凭证由官方工具处理；本软件不提供自己的 Claude.ai 登录表单，不代理模型请求。登录成功本身不会补齐 Token 历史。
3. 「读取本地数据」及自动刷新只核对官方 CLI 的本机 `auth status`、扫描本机日志、读取已有快照。**v0.1.21 已移除 v0.1.20 的实验性主动额度查询，没有可重新开启的隐藏开关。**
4. 「状态栏额度采集」默认不自动安装。用户开启后，转发器在正常终端 Claude Code 会话中接收官方状态栏提供的额度字段，保存必要元数据并保留原状态栏输出。新会话正常响应后才可能得到快照；不要为了生成统计额外发送模型请求。可随时关闭并恢复原设置。
5. 设置显示「本地采集」及数据范围。没有所选周期记录时，统计页说明最近本机记录日期，并提供数据设置入口；缺少数据不代表账号没有使用。

普通网页或桌面聊天没有接入逐请求 Token 明细。桌面 Code、Cowork 和远程会话可能有不同记录来源，当前没有做完整适配。状态栏也不保证在桌面 Code 标签运行，不以登录成功推断已经覆盖这些客户端。

CLI 可来自 PATH、用户指定路径或桌面应用下载的内置工具。安装包不包含或修改 Claude Code；不读取 `.credentials.json`、钥匙串、浏览器 Cookie 或 OAuth 令牌。

参考：[官方状态栏字段](https://code.claude.com/docs/en/statusline#available-data)、[官方监控能力](https://code.claude.com/docs/en/monitoring-usage)、[凭证及使用边界](https://code.claude.com/docs/en/legal-and-compliance)。减少不明确的主动调用不构成平台授权或账号安全保证；不对外承诺「官方认证」或「零封号风险」。后续采集扩展应优先采用文档支持的方式。

## 额度与身份

- 当前身份通过官方本机登录状态核对；读取快照前后若身份变化则拒绝关联。未登录时不把旧邮箱作为当前登录；API key 与第三方后端不借用订阅快照。
- 官方状态栏快照必须带与当前账号一致的身份指纹；只保存指纹、采集时间、五小时 / 每周百分比和恢复时间。
- 桌面已有 `plan-usage-history.json` 只接受与当前账号组织相符的样本；只读本地文件，不调用桌面私有接口。该文件格式和存在性不保证稳定，未提供恢复时间时保持未知。
- 升级后，旧主动查询样本改为历史来源，保留原采集时间；刷新或重启不会让样本「变新」。无匹配指纹的缓存不显示百分比。
- 额度均以快照展示，并提供来源、采集时间。超过窗口长度、未来异常时间或已过恢复时间的样本不显示为可用额度，不自动变回 100%。历史数据不参与当前额度提醒或菜单栏实时百分比。
- 官方未提供订阅到期时间时继续显示「接口未提供」。不从本机 Token 反推订阅额度，不从额度百分比反推 Token 或成本。

## 统计与参考成本

扫描 `projects/**/*.jsonl`，只提取时间、项目、会话、模型、响应标识和 token 用量。流式内容块常重复携带相同响应 usage：按 message.id 去重，后续更完整用量更新同一条记录；复制文件和子代理副本使用相同稳定标识。没有响应标识、有效时间或非零用量的记录不计为请求记录。正文、工具参数和附件内容不存入数据库。

Claude 的 input_tokens 本身不含缓存读取和写入，因此本项目统一输入为 `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`；总 Token 再加输出。缓存命中是输入的子集，不重复加总。统计页“新增输入”包含未命中的缓存写入。

参考费用区分普通输入、缓存读取、5 分钟写入和 1 小时写入；按可用 TTL 分项估算，常见写入倍率为基础输入价的 1.25× / 2×。记录没有 TTL 明细时按 5 分钟参考价处理。已核对常用 Claude 模型参考价，带日期的模型 ID 可匹配对应基础型号，用户同名配置优先；未知模型不猜价格。加速、区域、工具等附加费用不包含在参考估算中。[官方价格](https://platform.claude.com/docs/en/about-claude/pricing)。

v0.1.24 已内置官方价格表中的 20 个型号及 Haiku 5.5 提示长度分档，新用户自动加载，升级保留用户自定义和删除选择；详见 [Claude 默认单价](claude-reference-pricing.md)。

Claude 日志未给出可靠逐请求生成速度或首字时间时显示 —，不用完整响应时间冒充首字时间。额度百分比是订阅窗口信息，不从本机 Token 数倒推，也不是余额或真实账单。

## 存储与设置保护

GPT 沿用原数据库 scope，Claude 使用 `claude:<配置目录>`，即使目录相同也不会混合两平台记录和账号缓存。数据库升级至版本 3，新增缓存写入字段，旧 Codex 数据保持不变。

macOS 采集器使用 Swift，Windows 采集器由 Dart 编译为独立 EXE，均无需另装语言运行时，无 Python / Node 运行依赖、不发起网络或模型调用。启用时复制到配置目录的私有 `quotamate/` 文件夹，应用搬迁不破坏原路径。只备份原 statusLine，不复制整个配置；macOS 相关目录 0700、元数据文件 0600；Windows 采集目录限定当前用户 / SYSTEM 权限。其他 Claude 设置保留；无效 JSON 不被覆盖。原状态栏命令继续由用户原配置决定，输出转发；为避免挂起设置超时保护。

状态栏采集在账号切换后需要重新绑定并新开会话。身份不匹配、数据缺失或版本不支持时保持未知。历史 Token 不强行归属于当前登录邮箱；只代表此配置目录内的本机记录，不包含 Claude 网页全部聊天或其他设备记录。

## 验证

测试覆盖流式去重、克隆、副本、增量尾行、重写、缓存写入计价、账号指纹与组织匹配、旧身份拒绝、设置保留与恢复、原输出透传、隐私字段过滤、两平台缓存隔离、重启选择、双语与明暗主题。回归测试通过受限 CLI 夹具验证启动、手动刷新和定时刷新只执行 auth status；不发 SDK 控制消息或模型请求。测试也覆盖旧样本升级、时间不变、零用量、身份变化、快照过期、空统计解释和双语设置入口。原生采集器测试只操作临时目录；不会进行真实登录或消耗真实额度。

开发时可运行 `dart run tool/claude_connection_check.dart` 做只读诊断：它用临时数据库验证导入，只输出是否连接、记录计数与 token 汇总，不输出邮箱、组织标识、对话或凭证。

## 额度与成本视图

账户额度使用已核对组织的桌面历史和已核对身份的本机快照，按实际采样时间绘点。单个采样只显示一个时间点。开启自动读取订阅日期时，也读取同一配置中已有的缓存额度字段，并核对账号 UUID、邮箱和组织。缓存的有效重置时间单列展示其原始采集时间。订阅开始和到期分别按原字段显示。

Token 与成本保留今日、近 7 天和近 30 天。当前周期为空时，可转到最近有记录的一天，金额、图表、明细及 CSV 随日期切换。只有部分请求可计价时显示小计和覆盖条数。诊断页显示今日计价覆盖及最近记录日期，桌面 Code 会话可按 Local、SSH、Cloud 环境定位日志。
